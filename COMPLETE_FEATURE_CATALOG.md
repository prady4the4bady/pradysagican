## 🚀 Quick Start

### Installation
```bash
git clone https://github.com/prady4the4bady/pradysagican.git
cd pradysagican
pip install -r requirements.txt
```

### Run All Tests
```bash
make test
# or
pytest tests/ -v
```

### Verify All 75+ Features
```bash
python -m pradysagican.verify_features
```

### Start the System
```bash
python -m pradysagican.cli start --heartbeat-interval 20
```

### Run Specific Phase
```bash
# Phase 5: Self-Referential Evolution
pytest tests/test_phase5_*.py -v

# Phase 6: Co-Evolution
pytest tests/test_phase6_coevolution.py -v

# Phase 7: Intelligence
pytest tests/test_phase7_intelligence.py -v

# Phase 8: Godmode
pytest tests/test_phase8_full_integration.py -v
```
