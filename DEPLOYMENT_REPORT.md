## 📈 DEPLOYMENT INSTRUCTIONS

### Prerequisites

```bash
# Required
Python 3.11 or higher
pip (Python package manager)
git (for version control)

# Optional
Docker (for containerized deployment)
Kubernetes (for orchestration)
```

### Local Deployment

```bash
# 1. Clone repository
git clone https://github.com/prady4the4bady/pradysagican.git
cd pradysagican

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run all tests
make test
# or
pytest tests/ -v

# 4. Verify all features
python -m pradysagican.verify_features

# 5. Start system
python -m pradysagican.cli start --heartbeat-interval 20
```

### Docker Deployment

```bash
# Build image
docker build -t pradysagican:latest .

# Run container
docker run -d \
  --name pradysagican \
  -e HEARTBEAT_INTERVAL=20 \
  pradysagican:latest

# Check logs
docker logs -f pradysagican
```

### Production Deployment

```bash
# 1. Push to registry
docker push your-registry/pradysagican:latest

# 2. Deploy to Kubernetes
kubectl apply -f deployment.yaml

# 3. Monitor
kubectl logs -f deployment/pradysagican
kubectl get pods -l app=pradysagican
```
