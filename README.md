## 🔐 Dual-Mode System

PRADYSAGICAN operates in one of two strictly segregated modes. Mode selection is enforced at the kernel level of `DualModeController`.

### GUARDIAN — Public Mode (Default)

The default mode for all public users, researchers, and commercial deployments.

- Full PII redaction (email, phone, SSN, credit card regex)
- Toxicity detection and refusal
- Ethical constraint enforcement (4 frameworks: utilitarian, deontological, virtue, care)
- Rate limiting and circuit breaker
- Emergency kill switch

```python
from pradysagican.safety.dual_mode import DualModeController, OperatingMode

controller = DualModeController()
# Default: GUARDIAN — all safety filters active
response = await controller.process(user_input)
```

### SOVEREIGN — Government / Restricted Mode

For government entities and authorized multi-party contexts only. Unrestricted operation with full audit trail.

| Requirement | Detail |
|---|---|
| Master credential | `[REDACTED — contact f20240323@dubai.bits-pilani.ac.in]` |

| Failed attempt policy | **5 failed attempts → permanent IP ban** |
| Audit trail | Every action logged immutably with timestamp + party IDs |

SOVEREIGN mode is locked behind `SovereignLock` — a separate module with HMAC credential verification, hardware fingerprint validation, and multi-party consensus. It cannot be bypassed from GUARDIAN mode without physical quorum sign-off.
