## ⚡ Install

**One command (recommended):**
```bash
git clone https://github.com/prady4the4bady/pradysagican.git && cd pradysagican && bash setup.sh
```

**Docker:**
```bash
docker pull prady4thebady/pradysagican:latest
docker run -p 8000:8000 prady4thebady/pradysagican:latest
```

**Make:**
```bash
make install   # install dependencies
make run       # start API server
make test      # run 152 tests
```

**pip (editable):**
```bash
pip install -e .
```
