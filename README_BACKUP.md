## 🔧 Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| `BUS-0 slow (>10ms latency)` | Too many probes or MAXWELL drift expensive | Reduce probe batch size; profile via `pytest -v --profile` |
| `Tests failing (regression)` | New code broke golden trajectory | Revert commit, check OUROBOROS rollback logs |
| `Memory usage spike` | MNEMOSYNE vector DB growing | Run `MAXWELL.entropy_release()` to prune old memories |
| `Provider chain fallback` | All APIs failed | Check `OLLAMA_HOST` is accessible, or use local llama.cpp |
| `Calibration drifting` | MIRROR curves stale | Run `pradysagican calibrate --domain=<domain> --retrain` |
| `Sovereignty mode stuck` | Waiting for quorum | Check if all 3+ approvers have signed via `pradysagican sovereign --status` |
