## 📚 Examples

### Example 1: Multi-Agent Research

```python
from pradysagican import PradysagiSystem

system = await PradysagiSystem.initialize()

# Spawn specialized agents
researcher = await system.spawn_agent("researcher")
analyst = await system.spawn_agent("analyst")
writer = await system.spawn_agent("writer")

# Assign complex task
result = await system.coordinate_agents(
    task="Research AI safety practices and produce a report"
)
```

### Example 2: Multi-Modal Processing

```python
from pradysagican.core import MultiModalIntegration

multimodal = MultiModalIntegration(system.hub)

result = await multimodal.process_multimodal(
    text="Analyze this image and transcribe the audio",
    image_path="/path/to/image.jpg",
    audio_path="/path/to/audio.wav"
)
```

### Example 3: Advanced RAG

```python
from pradysagican.core import AdvancedRAGSystem

rag = AdvancedRAGSystem(system.hub)

# Hybrid retrieval combining semantic + keyword search
documents = await rag.retrieve_context(
    query="How to implement causal inference?",
    strategy="hybrid",
    top_k=10
)
```

### Example 4: Fine-Tuning

```python
from pradysagican.core import FineTuningIntegration

finetuning = FineTuningIntegration()

# Create fine-tuning job
job = await finetuning.create_finetuning_job(
    model_name="llama2-7b",
    training_data="/path/to/training_data.jsonl",
    method="lora"
)

# Monitor progress
while True:
    status = await finetuning.monitor_job(job["id"])
    if status["status"] == "completed":
        break
```
